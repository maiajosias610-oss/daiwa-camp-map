# 带娃去哪儿 · 溜娃露营地图

一个纯前端的「广州周边溜娃露营地点推荐」页面。移动端优先，Liquid Glass 液态玻璃 UI，无需后端、无需安装。

**手机打开：** 直接用手机浏览器访问本页面地址（GitHub Pages 链接），建议加到主屏幕。

## 当前进度（2026-09-30）

- **数据**：覆盖公众号「真的叫啊珍」2024-08-18 至今全部 **703 篇**文章（正文仅本地留存，线上只保留标题+链接索引）
- **地点**：**35 个**精选地点卡（广东省内：广州各区 + 佛山/东莞/中山/江门开平等），坐标人工核对，按「离你最近」排序
- **文章库**：703 篇可搜索索引（广东 639 / 省外 64），默认只列省内
- **功能清单**：
  - 定位 / 快捷出发点，推荐按距离从近到远
  - 🧭 一键拉起高德地图导航（App 或网页版），附百度路线
  - 地区筛选（广州各区 / 省内城市）+ 标签筛选（免费/玩水/露营/室内…）+ 关键词搜索
  - 出行装备清单（可勾选）、行程提醒（出发日装备提示、预约提醒）
  - 周末天气与「是否适合露营」判断（open-meteo）
  - 语音搜索（浏览器支持时，微信内置浏览器自动降级为关键词搜索）
- **UI**：液态玻璃设计系统——8pt 栅格、玻璃卡 rgba(255,255,255,.45)+blur(14px)、柠檬黄激活胶囊 #F9F380、低饱和马卡龙辅助色、扁平单色 SVG 图标、圆角 20/16/999/28

## 版权说明

- 采用**链接聚合**模式：地点卡片为客观信息摘要（设施/交通/费用等事实信息），每个地点附来源文章链接；本页不存储、不传播任何文章正文与图片
- 信息整理自公开游记文章（含公众号「真的叫啊珍」等），版权归原作者所有
- 已通过 robots.txt + noindex 禁止搜索引擎收录，仅通过链接访问

## 目录结构

```
index.html            页面入口
css/style.css         液态玻璃设计系统
js/data.js            35 个精选地点（客观摘要 + 原文链接）
js/spot_coords.js     地点坐标（距离排序/导航用）
js/articles_index.js  703 篇文章索引（标题+链接+日期）
js/app.js             页面逻辑（无依赖，纯原生 JS）
```

## 更新流程

```

```
